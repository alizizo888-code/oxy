# OXY — Oxygen Maintenance WordPress Package

مستودع واجهة **OXYGEN** وإضافة ووردبريس لنشر مقالات صيانة المكيفات وتحديث المقالات المؤهلة.

## مكونات المستودع

- `index.html`: معاينة الواجهة العربية.
- `oxygen-ac-automation/oxygen-ac-automation.php`: إضافة ووردبريس، لوحة ناشر أكسجين، الجدولة، وصفحات الواجهة والمقالات.
- `oxygen-ac-automation/assets/page-part-01.txt` إلى `page-part-06.txt`: أجزاء مصدر الواجهة المضغوط.
- `build-plugin.py`: أداة استعادة ملفات المصدر المضغوطة محليًا.

## تثبيت الإضافة

1. نزّل مجلد `oxygen-ac-automation` أو استخدم حزمة ZIP الجاهزة المرفقة بالمحادثة باسم `oxygen-ac-automation.zip`.
2. من لوحة تحكم ووردبريس افتح **إضافات ← أضف إضافة جديدة ← رفع إضافة**، ثم ارفع ZIP وفعّله.
3. تنشأ الصفحتان `/oxygen-ac-home/` و`/oxygen-ac-articles/` تلقائيًا، وتُعيّن واجهة أكسجين صفحةً رئيسية للموقع؛ وتُخدم الصفحة كاملة عند الجذر `/`.
4. افتح قائمة **ناشر أكسجين** من لوحة الإدارة لتحديد الكلمات المفتاحية ومعدل النشر. إعدادات الناشر لا تظهر في الواجهة العامة.

## الجدولة اليومية

- يمكن اختيار **1 إلى 20 مقالة جديدة يوميًا**.
- يمكن اختيار **1 إلى 20 مقالة قديمة مؤهلة للتحديث يوميًا**.
- ينشر الجديد تلقائيًا افتراضيًا، أو يمكن تعطيل النشر التلقائي ليُحفظ كمسودة.
- يستخدم النظام WP-Cron. لضمان عمله حتى عند قلة الزيارات، اضبط Cron من Hostinger ليستدعي `/wp-cron.php?doing_wp_cron=1` كل 5–15 دقيقة متى كانت الخطة تسمح.
- تحديث المقال القديم يضيف معلومات ذات صلة ويحافظ على عنوانه ورابطه الدائم، ولا يعيد نشر النص نفسه كما هو. قد يكون العدد الفعلي أقل إذا لم تتوفر مقالات قديمة مناسبة أو عناوين فريدة.

## توليد المحتوى وSEO

يستخدم النظام قوالب عربية داخلية عند عدم ضبط مفتاح API، مع عناوين فرعية مرقمة، ومقدمة وخلاصة وأسئلة شائعة، وكلمات مفتاحية ووصف مختصر وحقول شائعة لـ Yoast SEO وRank Math. يمكن إضافة مفتاح OpenAI API اختياريًا من إعدادات الإضافة لتوليد نصوص مختلفة، وقد تترتب تكلفة على الاستخدام الخارجي.

**مهم:** 40 إجراءً للمحتوى يوميًا (20 جديدًا + 20 تحديثًا) لا يضمن تحسن الترتيب. تجنّب المقالات المتشابهة، وراجع دقة معلومات الخدمات والأسعار والتوافر؛ الجودة والمنفعة للمستخدم أهم من العدد.

## الخصوصية

لا تضف كلمات مرور أو مفاتيح API أو أرقام حسابات بنكية إلى مستودع عام. أُزيلت بيانات الدفع من حزمة الواجهة المرفقة، وأُغلقت نافذة إعدادات الواجهة القديمة التي كانت تعتمد على رمز محفوظ في JavaScript. إعدادات النشر الدائمة تُدار من لوحة ووردبريس بصلاحية `manage_options`.

## استعادة الواجهة محليًا

بعد تنزيل المستودع كاملًا، شغّل:

```bash
python build-plugin.py
```

يعيد السكربت إنشاء نسخة الواجهة من أجزاء المصدر المضغوطة، مع إزالة رمز الواجهة القديم وبيانات الدفع، ويترك ملف الإضافة الحالي دون استبدال.
