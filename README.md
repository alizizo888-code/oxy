# OXY — Oxygen Maintenance WordPress Package

هذا المستودع يحتوي على واجهة أكسجين للصيانة، وإضافة ووردبريس لعرض الواجهة وإدارة المقالات المجدولة.

## الملفات
- `index.html`: معاينة ثابتة/مشغل الواجهة.
- `oxygen-ac-automation/oxygen-ac-automation.php`: إضافة ووردبريس.
- `oxygen-ac-automation/assets/oxygen-maintenance-home.html.gz.b64`: نسخة مضغوطة من ملف الواجهة، مع استبدال بيانات الحساب البنكي بقيم تجريبية قبل نشرها في المستودع العام.

## التثبيت
1. ارفع `oxygen-ac-automation.zip` إلى **إضافات ← أضف إضافة جديدة ← رفع إضافة** في ووردبريس.
2. فعّل الإضافة. تنشئ صفحتي `/oxygen-ac-home/` و`/oxygen-ac-articles/` إذا لم تكونا موجودتين، دون تغيير الصفحة الرئيسية الحالية.
3. افتح لوحة **ناشر أكسجين** لتعديل معدل النشر والكلمات المفتاحية ورقم التواصل.
4. المعدل مضبوط على حد أعلى 20 مقالة جديدة و20 تحديثًا لمقالات قديمة يوميًا. يمكن اختيار 1–20 لكل منهما.

## النشر المجدول
يعتمد النظام على WP-Cron. لتوقيت أدق في استضافة Hostinger، اضبط Cron لاستدعاء wp-cron.php بشكل دوري. لا يعيد النظام نشر نسخة مطابقة من المقال القديم، بل يضيف تحديثًا ذا صلة للمقال المؤهل بعد انقضاء فترة الانتظار المحددة. إذا فشلت واجهة توليد المقالات، يتوقف عن نشر المقال غير المكتمل.

يمكن إدخال مفتاح OpenAI API اختياريًا من لوحة الإضافة لتوليد نصوص أوسع. من دون المفتاح يستخدم النظام قوالب عربية داخلية؛ لا توجد أي رسوم API إلا عند اختيار خدمة خارجية بمفتاح صالح.

## خصوصية
نسخة المصدر العامة لا تنشر اسم صاحب الحساب أو رقم الآيبان الموجودين في HTML الأصلي. يجب تحديث بيانات الدفع بصورة آمنة قبل استخدام الموقع حيًا.


## استعادة ملفات الإضافة والواجهة من المستودع
بعد تنزيل المستودع كاملًا، شغّل:
```bash
python build-plugin.py
```
يعيد السكربت تكوين نسخة HTML المعقّمة ونسخة gzip الاحتياطية وملف إضافة PHP من أجزاء المصدر. ثم اضغط مجلد `oxygen-ac-automation` وحده في ZIP وارفعه من لوحة إضافات ووردبريس.
- `index.html` يحمّل واجهة HTML من أجزاء `assets/page-part-01.txt` إلى `page-part-06.txt` عند استضافة الملفات مع دعم `DecompressionStream`.
- ملف ZIP الجاهز للتثبيت موجود كمرفق بالمحادثة، وليس مرفوعًا إلى المستودع.
- الإضافة تنشئ صفحتي `/oxygen-ac-home/` و`/oxygen-ac-articles/` بعد تفعيلها؛ لا تغيّر الصفحة الرئيسية الحالية تلقائيًا.
- جدولة النشر تعتمد WP-Cron. حدّد 1–20 مقالة جديدة و1–20 تحديثًا لمقالات قديمة يوميًا. التحديث يضيف معلومات جديدة ذات صلة ولا يعيد نشر النص المطابق.
- بيانات الحساب البنكي الأصلية أزيلت من النسخة العامة؛ اضبط بيانات الدفع بأمان على الموقع قبل الاستخدام الحي.
