# مرجع التصميم الداخلي (Design reference)

صور مرجعية رفعها المالك لتكون الاتجاه البصري والوظيفي لواجهات: العميل، الفني، مشرف العمليات، المالك.
**الأرقام والأسماء في الصور أمثلة شكلية (٥٤ فنيًا، ١٤٢ طلبًا، ٤٨٬٦٥٠ ر.س …) ولا تُعرض في التطبيق كبيانات حقيقية أبدًا.**
الاتجاه البصري في الصور: أخضر داكن (#0a6b3d تقريبًا) + خلفية فاتحة مزرقة + بطاقات بيضاء بزوايا كبيرة + شارات صغيرة ملونة.

| # | الشاشة في الصورة | الصفحة المقابلة الآن | الفجوة |
|---|---|---|---|
| 01 | اختيار نوع الحساب + دخول بالجوال/الإيميل (OTP) | صفحة الدخول (Login) | بطاقات نوع الحساب (عميل/فني/إشراف) بدل تبويب واحد |
| 02 | الرئيسية للفني: متصل/غير متصل، أرباح اليوم، المهمة الجارية، الطلبات المتاحة فورًا بالتصنيف | `/staff` (الفني) + الرادار | شريط أرباح، بطاقة مهمة جارية، فلاتر التخصص، قبول فوري/اعتذار |
| 03 | تفاصيل مهمة الفني: مراحل (وصول/فحص/تنفيذ/فاتورة)، صور قبل/بعد، بنود الفاتورة، ملخص الحساب، OTP تسليم | `OrderDetailStaff` | مراحل مرئية، صور قبل/بعد، بنود فاتورة قابلة للإضافة، OTP إنهاء |
| 04 | تتبع العميل المباشر: وقت الوصول، خريطة، بطاقة الفني، الضمان | `ClientOrderDetail` | خريطة مباشرة للفني + ETA |
| 05 | محادثة العميل والفني: موقع، صور، صوت، ردود سريعة | الدردشة | ردود سريعة + إرسال الموقع |
| 06 | تقييم بعد الخدمة: نجوم، تفاصيل الأداء، إكرامية | غير موجود | شاشة تقييم كاملة |
| 07 | لوحة المالك: مؤشرات، خريطة حية، جدول الطلبات، جودة، مالية | `/staff` (المالك) | مؤشرات حقيقية فقط |
| 08 | إدارة شبكة الفنيين: جدول، تقييم، SLA، مستحقات | الفنيون / طلبات الفنيين | جدول أداء الفنيين |
| 09 | غرفة العمليات: مؤشرات + جدول التفويض + فحص الجودة + توزيع الورديات | `OperationsRoom` (أُعيد بناؤها) | جدول تفصيلي + جودة + ورديات |
| 10 | مركز الإعلانات والاتصال الموحد (Google/TikTok/Cloud API) | — | **خارج النطاق الآن**: يحتاج واجهات مدفوعة |
| 11 | تفعيل الدخول بالبصمة | `PasskeyOffer` (موجود) | تحسين الشكل فقط |

## قيود لا تتغير
- كل شيء مجاني: لا واتساب Cloud API ولا خدمات ذكاء مدفوعة.
- لا تخزين كلمات سر أو آيبانات في الكود.
- لا أرقام وهمية في الواجهات الحية.
